El Hawasneya Language — نسخة قابلة للتثبيت على الهاتف

طريقة الاستخدام:
1) ارفع محتويات هذا المجلد كما هي إلى استضافة تدعم HTTPS (مثل GitHub Pages أو Netlify أو Vercel).
2) افتح رابط الموقع المنشور من Chrome على هاتف Android.
3) من قائمة ⋮ اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
4) أكّد الإضافة؛ ستظهر الأيقونة على الشاشة الرئيسية.

مهم: فتح index.html مباشرة من مدير الملفات لا يتيح تثبيت PWA بشكل موثوق. يلزم رابط HTTPS.
